# PengTools 晴空棱镜品牌标识

## 标识含义

“PengTools”晴空棱镜（Prism）品牌标识由紫色圆角棱镜底板、明亮白色字母 P 主体以及右上角淡青色棱镜星（Prism Star）构成：

- 紫色棱镜底板：`#9E8CF2` 至 `#6453D5` 渐变圆角方形（`rx="19"`），象征统一、现代、高效的聚合工作台。
- 白色 P 主体：干练稳固的字母 P 路径，承载工具箱核心业务能力。
- 右上淡青棱镜星：`#D7FBF2` 棱镜折射星标，象征灵动激发、快速洞察与智能辅助。
