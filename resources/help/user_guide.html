1. 3 分钟上手与界面减负

PengToolsHub 把日常开发、数据库查数、需求发版、SSH 日志排查、接口抓包、测试数据生成与内网大模型能力整合到一个本地窗口里，所有业务数据仅存本机，不依赖公网。

觉得功能多、上手复杂？先用好这 4 个减负开关

  1. 侧边栏「精简 / 全部」：在左侧导航顶部切换。「精简」默认折叠低频分组让菜单更清爽，点分组名随时展开，不会禁用任何功能。
  2. 悬停星标「常用置顶」：鼠标悬停在左侧任意模块上，点右侧 ☆ 即可固定到最上方的「常用置顶」区。
  3. 首页「简洁 / 完整」：在首页主卡右上角一键切换。「简洁」只保留搜索、常用工具和项目进度；「完整」展开上线日历、阶段统计与日报概览。
  4. 全模块分步「引导」按钮：在数据中心、需求管理、发版联动、接口文档、日志排查、AI 日志排查、命令库、接口排查、格式工具、测试数据、设置页顶栏均配有轻量 引导 按钮，点一下即弹出聚光灯式「下一步 → 下一步」交互向导。
安全与离线原则：程序支持单实例防重复打开；所有配置与台账仅保存在程序同级 data/ 目录，无云端上传。

3. 首页工作台

  • 全局搜索框：支持搜索推进中的需求、模块工具与常用命令，方向键选定回车直达。
  • 简洁 / 完整切换：右上角带平滑过渡反馈的视图开关，偏好自动记住。
  • 项目进度（列表 / 看板）：看板模式支持直接拖动卡片推进需求阶段，也可点「新建需求」就地抽屉录入。
  • 称呼修改：点击问候语旁的昵称即可就地编辑，回车保存。

4. 数据中心（多库查询）

  1. 新建连接：点击左侧目录「新建连接」，按引擎填写主机、端口、库名与凭据，支持 SSH 隧道与 TLS 配置。
  2. 独立标签工作区：双击左侧连接在右侧打开专属标签，每个标签固定绑定其连接 ID，切换标签不串库、不中断查询。
  3. 显式操作更安全：打开标签不自动连库、不自动扫描全量 Redis Keyspace，测试与查询均由你显式触发。

5. 智能助手（模型聊天 / Agent 工作台）

  • 配置方式：进入「设置 → 模型服务」添加并启用内网 OpenAI 兼容或 Anthropic 兼容接口，支持多模型管理与连通测试。
  • 模型聊天：支持流式输出、代码块滚动、附件分析与防抖会话搜索；思考过程仅留内存不落盘污染历史。
  • 安全策略：凭据与敏感错误自动脱敏，只使用你明确勾选的内网模型。

6. 需求管理与发版联动

6.1 需求管理

  • 精准搜索：输入中文时按原文精确匹配（不再误匹配无关首字母）；输入英文字母或编号时走拼音全拼与首字母匹配。
  • 顶栏与新增弹框瘦身：高频操作「新建需求」直达，批量操作（拉取最新、一键提签、SVN/目录导入、登记缺陷）统一收进「更多 ▾」；新增需求中勾选多个所属系统时，「开发分支/目录绑定」默认折叠为一行摘要，需要时点击展开单行填写。
  • SVN 与文件库：复用本机 SVN 命令行缓存，软件不保存 SVN 密码；支持检出、更新、提交、锁/解锁与拖入文件。

6.2 发版联动与接口文档更新

  • 需求详情「更多 ▾ → 准备本次升级」可一键带入发版联动，按 23 列标准模板生成发版 Excel。
  • 接口文档更新可根据建表/改表 SQL 批量更新本地接口 Word 模板。

7. 日志排查与 AI 日志排查

7.1 人工排查（单机终端 / 多机截取）

  • 服务器管理：在左侧「服务器与日志 → 管理」或顶栏「更多操作」维护主机地址、认证方式与各服务日志路径。
  • 单机会话：点击顶栏紫色「连接本会话」打开交互式 SSH 终端，支持多标签并发连接不同主机，左侧可预览日志、看尾部和浏览远端目录。
  • 多机截取：切到「多机截取」并行检索多台服务器日志并流式导出本地（不在远端写临时文件），导出后可一键送入「AI 日志与系统排查」。

7.2 AI 日志与系统排查

  • 支持 历史日志分析、Linux 实时监控、仅实时日志 三种模式；左侧「异常事件 / 已采集日志 / 实际覆盖范围」打开即完整展示。
  • 点「展开设置」选择本地文件或服务器日志并启动采集，在右侧选择内网模型并勾选确认后，即可「分析所选」或让 AI 整理故障报告。
  • 发送给模型的日志片段强制清洗密码与 Token；所有采集只做只读查询，绝不修改或重启远端服务。

8. 命令库与 AI / 终端联动

  • 119 条实战模板 / 11 大分类：包含日志查询（含时间段与分钟报错峰值）、Java / JVM 排查（jps / jstat / jstack / top -Hp / jmap）、进程、网络（TCP 状态分布、HTTP 耗时拆解）、磁盘（lsof +L1 幽灵大文件）、容器与 K8s 等，支持右键置顶与自定义命令。
  • AI 命令助手：右侧内置「AI 命令助手」，输入白话需求可让内网模型生成只读命令，或点「AI 解释当前命令」拆解参数含义与风险。
  • 一键联动日志排查：点 送到日志排查终端 自动跳到 SSH 终端并填入命令栏；点 AI 日志排查 带入命令上下文切到 AI 排查页。
安全红线：严禁收录或生成 rm / rmdir / unlink / shred / find -delete 等删除指令；送到日志排查终端也只填入输入框、绝不自动执行，修改状态的高风险命令仍需二次确认。

9. 接口排查与格式工具

9.1 接口排查（HTTP / HTTPS 抓包与请求测试）

  1. 点击右上角「开始监听」启用本机 127.0.0.1 抓包代理；首次抓 HTTPS 请在顶栏「更多 ▾ → 安装 HTTPS 抓包证书」（随时可一键移除）。
  2. 完全退出并重新打开 Chrome / Edge 访问业务页，请求会实时进入左侧列表，支持状态、慢请求与 JSON/XML 筛选。
  3. 点选记录可在右侧查看概览/请求/响应，并一键「送格式工具」或切到「请求测试」按环境重放。
代理恢复提醒：正常点「停止监听」或关闭软件会自动恢复 Windows 系统代理。若异常强杀导致网页不通，可在「更多 ▾ → 恢复系统代理」一键修复，或重启软件自动清理。

9.2 格式工具（含图片 / PDF 转 Base64）

内置 JSON（支持 2 万节点快速搜索与树/文联动）、XML、SQL、文本与编码辅助，以及 图片 / PDF 转 Base64（支持选文件、拖拽或粘贴剪贴板截图转纯 Base64 / Data URI / HTML / CSS，也支持粘贴 Base64 还原图片预览并另存文件；大文件自动后台编码并截断界面预览防卡顿），全程离线不上传。

10. 测试数据、日报与个人空间

  • 测试数据（证件 + 车辆三合一）：已将原「证件类型」与「车辆 VIN」合并为单一全宽模块，顶部直接切换「个人证件」「单位证件」「车辆 VIN」，支持全随机或按条件批量生成、双击复制与 CSV 导出。
  • 日报：按月归档，支持「带入昨日计划」「复制为今日」「插入图片」和需求一键写入；切换日期会暂存草稿，确认后请点「保存日报」。
  • 自我学习：本地 Word / Excel / 文本知识库，支持防抖搜索与后台异步导入大文件。

12. 常见问题 FAQ

Q1：之前单独的「车辆 VIN」和「加解密」去哪了？

「车辆 VIN」已合并到左侧「开发工具 → 测试数据」的第 3 个页签（个人证件 / 单位证件 / 车辆 VIN 一站式切换）；「加解密」因网关逻辑变更已下线隐藏，同时减少了启动预热和内存占用。

Q2：需求搜索中文和拼音怎么配合？

输入中文按中文原文精准匹配（不会误匹配无关首字母）；输入英文字母或拼音首字母（如 cxcb、zizhu）自动走拼音检索。

Q3：抓包后列表为空或网页连不上网？

列表为空请确认已点击「开始监听」并完全重开浏览器（HTTPS 需在「更多 ▾」安装本机证书）；网页连不上网请点「更多 ▾ → 恢复系统代理」或重启一次软件自动清理残留代理。

Q4：命令库的 AI 助手提示未配置内网模型？

请先到「设置 → 模型服务」添加并启用内网模型，再回到命令库点「刷新模型」；未配置模型时，119 条内置命令与「送到日志排查终端」仍可直接使用。

Q5：功能太多记不住怎么用？

按 Ctrl + K 搜名字秒跳任意模块；打开陌生页面点右上角 引导 按钮走一遍「下一步 → 下一步」高亮向导，一分钟就能上手。
