1. 3 分钟上手与界面减负

PengToolsHub 把日常开发、数据库查数、需求发版、SSH 日志排查、接口抓包、报文加解密与内网大模型能力整合到一个本地窗口里，所有业务数据仅保存在本机，不依赖公网。

觉得功能多、界面复杂？先用好这 4 个减负开关

  1. 侧边栏「精简 / 全部」：在左侧导航顶部切换。默认「精简」会自动折叠低频分组，只留当前高频区；点击任意分组名随时展开，不会隐藏或阉割任何功能。
  2. 悬停星标「常用置顶」：鼠标悬停在左侧任意模块上，点右侧 ☆ 即可钉到顶部「常用置顶」区。
  3. 首页「简洁 / 完整」：在首页主卡右上角切换。「简洁」视图只保留搜索框、常用工具和项目进度；「完整」视图展开上线日历、阶段统计和日报概览。
  4. 分步交互「引导」按钮：在数据中心、需求管理、接口排查、日志排查、AI 日志排查、命令库顶部均有轻量 引导 按钮，不会用时点一下即可按「下一步 → 下一步」高亮真实按钮带你走一遍。
安全与离线原则：软件支持单实例启动；重复运行会直接激活已有窗口。业务配置与台账全部保存在程序同级 data/ 目录，无云端上传。

3. 首页工作台

  • 全局搜索框：支持搜索在推进的需求、模块工具与常用命令，方向键选择后回车直达。
  • 简洁 / 完整切换：右上角一键切换，状态自动记忆，重启软件后保持你的习惯。
  • 项目进度（列表 / 看板）：支持列表与看板切换；看板模式下可直接拖动卡片推进需求阶段，也可以点右上角「新建需求」就地抽屉录入。
  • 称呼修改：点击问候语旁的昵称即可就地编辑，回车保存。

4. 数据中心（多库查询）

  1. 新建连接：点击左侧目录「新建连接」，按引擎填写主机、端口、库名与凭据；需要跳板机或加密传输时可配置 SSH 隧道 / TLS。
  2. 独立标签工作区：双击左侧连接在右侧打开专属工作区标签，每个标签固定绑定其连接 ID，切换标签不会串库，也不会中断其它标签的查询。
  3. 显式操作更安全：打开工作区默认不自动连库、不自动扫描全量 Redis Keyspace，测试连接与执行查询均由你显式触发。
提示：不熟悉目录与多标签操作时，点右侧标签栏右上角 引导 即可开启 3 步高亮向导。

5. 智能助手（模型聊天 / Agent 工作台）

  • 模型配置：在「设置 → 模型配置」中添加内网 OpenAI 兼容或 Anthropic 兼容接口并启用，支持多模型切换与连通性测试。
  • 模型聊天：多轮对话、代码高亮、流式输出、附件发送与会话防抖检索；思考过程仅在当前内存展示，不落盘污染历史记录。
  • 隐私保护：敏感错误与凭据字段发送前自动脱敏清洗；不自动切换未授权模型。

6. 需求管理与发版联动

6.1 需求管理

  • 精准搜索：输入中文时严格按原文匹配（不再误匹配无关拼音首字母）；输入英文字母或编号时支持全拼与首字母检索。
  • 顶栏与详情瘦身：顶栏聚焦「搜索 / 筛选 / 新建需求 / 更多 ▾ / 引导」，批量操作（拉取最新、一键提签、SVN 导入、目录导入、登记缺陷）统一收纳在「更多 ▾」菜单中。
  • 新增需求更紧凑：勾选多个所属系统时，「开发分支 / 本地目录绑定」默认收起为一行摘要，需要配置时点击展开，按单行清爽编辑每个系统的分支与目录。
  • 文件库与 SVN：支持检出、更新、提交、锁/解锁与拖入文件；认证复用本机 SVN 缓存，软件不存 SVN 密码。

6.2 发版联动与接口文档更新

  • 在需求详情「更多 ▾ → 准备本次升级」可一键勾选该需求并带入 SQL 到「发版联动」，按 23 列内置模板生成标准发版 Excel。
  • 「接口文档更新」可根据 SQL 变更与本地模板生成或更新 Word 接口文档。

7. 日志排查与 AI 日志排查

7.1 人工排查（单机终端 / 多机截取）

  • 服务器管理：在左侧「当前主机 → 管理」或顶栏「更多操作」维护 SSH 主机、账号/密钥与各服务日志路径。
  • 单机会话：点顶栏紫色「连接本会话」打开独立交互终端，可开多个标签同时连不同服务器，左侧可直接预览日志、看尾部或浏览远端目录。
  • 多机截取：切到左侧「多机截取」分段，勾选多台主机与服务并发检索关键字，支持流式导出到本地（不在远端写临时文件），导出后可一键送入「AI 日志与系统排查」。

7.2 AI 日志与系统排查

  • 支持 3 种排查模式：历史日志分析（本地或远端文件）、Linux 实时监控（CPU/内存/磁盘/服务/端口）、仅实时日志。
  • 点左上角「展开设置」选择目标并启动采集，候选异常会自动聚合到「异常事件」表；右侧选择内网模型并勾选确认后即可点「分析所选」或让 AI 整理故障报告。
  • 发给模型的日志片段会强制清洗密码、Token 等敏感字段；只做只读查询，绝不自动修改或重启服务。

8. 命令库与 AI / 终端联动

  • 119 条实战模板：覆盖日志截取（含时间段与分钟报错峰值）、Java / JVM 排查（jps / jstat / jstack / top -Hp / jmap）、进程、网络（TCP 状态统计、HTTP 分段耗时拆解）、磁盘（lsof +L1 幽灵大文件定位）、容器与 K8s 等 11 大分类，支持右键置顶与自定义命令。
  • AI 命令助手：右侧内置「AI 命令助手」，输入白话场景（如“查 8080 端口占用并看最近 100 行报错”）可调用内网模型生成只读排查命令，也可点「AI 解释当前命令」逐段讲清参数含义与风险。
  • 与日志排查无缝联动：点击右下角 送到日志排查终端 会自动跳转到「日志排查」并将命令填入 SSH 命令输入框；点击 AI 日志排查 会带入当前命令上下文切到 AI 排查页。
安全红线：命令库严禁收录或生成 rm / rmdir / unlink / shred / find -delete 等删除命令；发送到日志排查终端也只填入输入框、绝不自动执行，修改状态的高风险命令仍需二次确认。

9. 接口排查与网关加解密

9.1 接口排查（HTTP / HTTPS 抓包与请求测试）

  1. 点击右上角「开始监听」启动本机 127.0.0.1 代理；首次抓取 HTTPS 明文时，可在「更多 ▾ → 安装 HTTPS 抓包证书」安装仅限当前用户的本地根证书（随时可一键移除）。
  2. 完全关闭并重新打开 Chrome / Edge 访问业务页，请求会实时显示在左侧列表中，支持状态、慢请求、JSON/XML 等筛选。
  3. 点击左侧记录可在右侧查看概览、请求、响应，并支持一键送入「格式工具」「加解密」或切到「请求测试」按环境重放。
代理恢复提醒：正常点「停止监听」或退出软件都会自动恢复 Windows 系统代理。若因异常强制结束导致网页打不开，可在接口排查顶栏「更多 ▾ → 恢复系统代理」一键修复，或重启软件自动清理。

9.2 网关加解密

支持网关 SM2 + SM4 报文解密查看，从接口排查「送入加解密」可自动带入报文与识别到的 Key；密钥与报文默认只在内存处理、不落盘。

10. 日报、格式与辅助工具

  • 日报：左侧按月归档，支持「带入昨日计划」「复制为今日」「插入图片」；未保存切换日期会自动留草稿，确认无误请点「保存日报」。
  • 格式工具：JSON 树视图支持 2 万节点快速搜索定位、XML / SQL 格式化、Base64 / URL / 时间戳 / 堆栈离线处理。
  • 证件类型 / 车辆 VIN：纯离线生成与校验测试数据。
  • 个人空间：支持本地 Word / Excel / 文本资料归档、搜索防抖过滤，大文件导入在后台线程执行不卡界面。

12. 常见问题 FAQ

Q1：需求搜索中文时能搜拼音吗？

输入中文时按中文原文精准匹配（不会误召回无关首字母）；输入英文字母或拼音首字母（如 cxcb、zizhu）时自动走拼音匹配。

Q2：抓包开始后列表一直是空的？

  • 确认右上角按钮已处于「监听中」状态；
  • 完全退出浏览器进程后重新打开再访问目标页面；
  • 抓 HTTPS 时确认已在「更多 ▾」安装了本机 HTTPS 抓包证书；
  • 检查左侧筛选标签是否误勾选了「失败」或「慢请求」。

Q3：抓包异常退出后浏览器连不上网？

打开接口排查顶栏「更多 ▾ → 恢复系统代理」，或重启一次 PengToolsHub（启动会自动清理残留代理）；也可在 Windows「设置 → 网络和 Internet → 代理」里手动关闭代理。

Q4：命令库的 AI 助手提示未配置内网模型？

请先到「设置 → 模型配置」添加并启用内网大模型接口，回到命令库点「刷新模型」即可使用；未配置模型时，119 条内置命令和「送到日志排查终端」依然全部可用。

Q5：找不到某个模块或觉得菜单太长？

按 Ctrl + K 直接搜模块名即可秒跳；平时可以把左侧切到「精简」，并把常用模块点星标 ☆ 固定在最上方。
