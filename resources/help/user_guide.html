1. 新手 3 分钟上手与界面减负

PengToolsHub 把数据库查数、需求与发版、SSH 日志排查、接口抓包、格式转换、测试数据与内网大模型整合到一个纯本地桌面窗口。第一次打开不用背功能，照着下面 4 步就能立刻顺手：

第 1 步 · 精简菜单：左侧导航顶部默认在 精简 模式，低频分组自动折叠；想看全部分组点 全部，或直接点任意分组标题展开（不隐藏任何功能）。
第 2 步 · 置顶常用：鼠标移到左侧你每天要用的模块上，点右侧出现的小星星 ☆，它会立刻固定到最上方的「常用置顶」。
第 3 步 · 首页切简洁：首页主卡右上角点 简洁 只留搜索、常用工具和项目进度；需要看上线日历与统计再点回 完整。
第 4 步 · 不会就点引导：所有核心页面右上角/顶栏都有 引导 按钮，点一下就会亮起聚光灯，按「下一步 → 下一步」手把手带你认一遍按钮。

3. 首页工作台操作步骤

步骤 1：按 / 或点顶部搜索框，输入需求标题、工具名或「新建需求」「写日报」，回车直达。
步骤 2：在「项目进度」右上角可切 列表 / 看板；看板模式下按住卡片拖到下一阶段列即可更新状态。
步骤 3：点击「新建需求」可在当前页右侧抽屉快速录入，无需来回切页；点击问候语旁的昵称可直接改称呼。

4. 数据中心（多库查数操作步骤）

步骤 1 · 新建连接：点击左侧目录的 新建连接，选好数据库类型（Oracle / MySQL / OceanBase / 达梦 / Redis / MongoDB），填主机、端口、账号与库名（需要跳板机时在弹窗里配 SSH 隧道 / TLS）。
步骤 2 · 双击打开工作区：在左侧连接树中双击目标连接，右侧会新开一个独立标签页；每个标签固定绑定自己的连接 ID，切换标签绝不串库。
步骤 3 · 显式连接与查数：工作区默认不自动连库。先点「测试/连接」，再浏览库表、执行只读 SQL 或按前缀浏览 Redis Key / Mongo 集合。

5. 智能助手（模型配置与对话操作步骤）

步骤 1 · 添加内网模型：进入左侧底部 设置 → 模型服务，填写内网大模型接口地址（支持 OpenAI 兼容与 Anthropic 兼容）、API Key 和模型名，点「测试连通」并勾选启用保存。
步骤 2 · 开始对话：打开 智能助手 → 模型聊天，顶部选好已启用的模型，输入问题按 Enter 发送（Shift+Enter 换行），支持附带代码/文本/图片附件。
步骤 3 · 检索历史：左侧会话列表支持实时防抖搜索、右键重命名或删除；模型思考过程仅内存展示，不污染历史记录。

6. 需求管理与发版联动操作步骤

6.1 需求管理

步骤 1 · 录入或导入：点顶栏紫色 新建需求 手工登记；若已有本地目录或 SVN 地址，点旁边 更多 ▾ 选择「通过 SVN 路径导入」或「通过需求目录导入」。
步骤 2 · 快速查找：顶部搜索框输入中文按原文精准匹配，输入字母/编号走拼音与首字母匹配，右侧可叠加月份、系统、类型筛选。
步骤 3 · 推进与文件管理：选中左侧需求后，点右侧上方进度节点即可改阶段；在「文件库」直接拖入文件、更新或提交 SVN；在「测试点」「SQL / 联动」记录明细。
步骤 4 · 写日报与提签：点 写日报 把当前需求进展自动带进今日日报；发版前点顶栏 更多 ▾ → 一键提签 或详情 更多 ▾ → 准备本次升级。

6.2 发版联动与接口文档更新

发版联动：① 选定「升级日期」→ ② 勾选参与发版的需求/BUG → ③ 切到「SQL 整理」按系统核对去重 → ④ 一键生成 23 列标准发版 Excel。
接口文档更新：① 选择接口文档所在目录并在左侧点选模板 DOCX → ② 在右侧粘贴或从需求带入变更 SQL → ③ 点右上角主按钮生成新的本地 Word 稿（不覆盖原模板）。

7. 日志排查与 AI 日志排查操作步骤

7.1 人工排查（单机 SSH / 多机截取）

步骤 1 · 配服务器：点左侧「服务器与日志」卡片的 管理，添加主机 IP、端口、账号密码/密钥以及各服务的日志路径。
步骤 2 · 连终端（单机）：下拉选中主机后，点顶栏紫色 连接本会话 打开交互终端；下方可选择服务一键看尾部、预览日志、关键字截取或浏览远端目录。
步骤 3 · 并行查多机：切到左侧 多机截取 分段，勾选多台主机与服务，输入关键字（支持逗号多词），点击导出即并行流式拉回本地（不在服务器写临时文件）。

7.2 AI 日志与系统排查

步骤 1 · 选排查方式：切到顶部 AI 日志与系统排查 标签，选择「历史日志分析」「Linux 实时监控」或「仅实时日志」。
步骤 2 · 选目标并采集：点左上角 展开设置 选择本地文件（或多机截取刚导出的日志）或远端服务器与路径，点右侧 读取文件 / 开始监控。
步骤 3 · 让 AI 定根因：左侧「异常事件」表出现聚合异常后，在右侧选择内网模型并勾选「确认使用所选内网模型」，点 分析所选 或直接在下方提问，也可点 报告 让 AI 整理故障草稿。

8. 命令库与 AI / 日志排查联动操作步骤

步骤 1 · 找命令与填空：在左侧搜场景（如 死锁、幽灵文件、HTTP 耗时、报错峰值）或切到 Java / JVM 排查 等 11 个分类，在参数栏改一下 PID、端口或日志路径，预览区自动生成带安全转义的命令。
步骤 2 · 用 AI 定制或解释：找不到现成模板时，在右侧「AI 命令助手」输入白话需求点 AI 生成命令；看不懂某条复杂命令就点 AI 解释当前命令。
步骤 3 · 一键联动执行：点右下角 送到日志排查终端 会自动跳到 SSH 终端并把命令填进输入框（绝不自动执行，核对主机无误后按回车运行）；或点 AI 日志排查 带入上下文继续分析。
安全红线：命令库禁止收录和生成 rm / rmdir / unlink / shred / find -delete 等删除指令；修改系统状态的高风险命令在复制和发送到终端前均强制二次确认。

9. 接口排查（抓包与请求测试操作步骤）

步骤 1 · 开启监听：点击右上角紫色 开始监听 启动本机 127.0.0.1 代理；首次抓 HTTPS 明文请先点顶栏 更多 ▾ → 安装 HTTPS 抓包证书（随时可一键移除）。
步骤 2 · 重开浏览器抓包：完全退出并重新打开 Chrome / Edge 访问目标业务页面，请求会实时流进左侧列表，可用状态、慢请求、JSON/XML 标签快速过滤。
步骤 3 · 查报文与重放：选中左侧任意请求，右侧查看概览/请求/响应，可一键 送格式工具 美化，或切到 请求测试 按保存的环境地址改参重发。
步骤 4 · 停止恢复代理：排查完点右上角 停止监听 即自动恢复 Windows 系统代理（会话记录保留不清空）。
异常断网急救：若因任务管理器强杀进程导致网页打不开，点接口排查顶栏 更多 ▾ → 恢复系统代理，或重启一次软件即可自动清理残留代理。

10. 格式工具（含图片 / PDF 转 Base64 操作步骤）

10.1 图片 / PDF ↔ Base64（双向互转）

转成 Base64：打开 格式工具 → 图片 / PDF 转 Base64，支持 ① 点 选择图片 / PDF、② 把文件直接拖进左侧虚线框、或 ③ 截图/复制文件后点 粘贴剪贴板图片；顶部可切换纯 Base64 / Data URI / HTML / CSS 与 76 列换行，右侧点 复制 Base64 或 导出 .txt（大 PDF 自动截断界面预览防卡顿，复制和导出始终为完整内容）。
Base64 还原文件：把已有 Base64（支持纯串、Data URI、带引号或 src="..."）粘贴到右侧编辑框，点顶部 Base64 还原预览，左侧立即展示图片缩略图或 PDF 信息，再点左侧顶栏 保存还原文件… 另存回本机。

10.2 JSON / XML / SQL / 文本辅助

顶部直接切换对应页签：JSON 支持 2 万节点快速搜索与树/文联动定位，XML/SQL 离线美化压缩，文本辅助涵盖 URL、Unicode、时间戳与 Java 堆栈提取，全程不落盘。

11. 测试数据、日报与设置操作步骤

  • 测试数据（证件 + 车辆三合一）：① 打开 开发工具 → 测试数据 → ② 顶部选「个人证件」「单位证件」或「车辆 VIN」→ ③ 选全随机或指定条件后点 生成 → ④ 双击单格复制，或底部一键复制全部 / 导出 CSV。
  • 日报：① 左侧选今天或历史日期 → ② 点 带入昨日计划 或直接填写 4 个分区（支持粘贴/拖入图片）→ ③ 点 保存日报 落盘。
  • 设置：① 左侧按 6 大分类切换（外观 / 悬浮工具栏 / 提醒与关闭 / 安全与安测 / 数据库客户端 / 模型服务）→ ② 修改后点右下角 应用并保存偏好 生效。

12. 数据目录、升级与常见问题 FAQ

运行方式本机数据目录
源码开发运行项目目录下 data/
打包版运行<PengToolsHub.exe 同级>/data/

无损升级：替换程序文件即可，切勿删除同级 data/ 目录，所有连接、需求台账、服务器与日报都会完整保留。

Q1：之前单独的「车辆 VIN」和「加解密」去哪了？

「车辆 VIN」已合并到 开发工具 → 测试数据 第 3 个页签；「加解密」因业务逻辑变更已下线隐藏，同时提升了启动速度、降低了内存占用。

Q2：抓包后列表是空的或网页连不上网？

列表为空请确认已点「开始监听」并完全退出重开浏览器（HTTPS 需在「更多 ▾」装证书）；网页连不上网点「更多 ▾ → 恢复系统代理」或重启一次软件即可恢复。

Q3：需求搜索中文和拼音怎么用？

输入中文按中文原文精准匹配（不再误匹配无关拼音首字母）；输入英文字母或首字母（如 cxcb、zizhu）自动走拼音检索。

Q4：图片 / PDF 转 Base64 有大小限制吗？

单文件上限 25 MB；超过 1 MB 自动后台线程编码，超过 12 万字符自动截断编辑框显示防止界面卡顿，点「复制 Base64」和「导出 .txt」都会完整输出。
