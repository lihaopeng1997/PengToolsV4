### 2.2 SVN 适配对照表（finishing-a-development-branch 核心）

| Git 概念 | SVN 等价 |
|---------|---------|
| `git merge` | `svn merge` + `svn commit` |
| `git branch` | SVN 分支目录（如 `/branches/feat-xxx/`） |
| `git push -u` | `svn commit`（无远程推送概念） |
| `git worktree` | **不适用**（PengTools 无此概念，已移除） |
| `git stash` | `svn diff > patch`，恢复时 `patch -p0 < patch` |
| `PR / Pull Request` | 代码审查通过后手动 `svn commit` |

### 2.3 翻译适配策略（通用规则）

- **Git→SVN**：只改有明显 Git 语义特定表达的词汇（merge/branch/push/worktree）；泛化词汇（commit/提交哈希/标签）不强制改
- **TS→Python**：TypeScript 示例→Python 示例；jest→pytest
- **联网依赖**：移除 `render-graphs.js` 等依赖网络文件的片段
- **dispatching-parallel-agents**：合并进 `executing-plans` 的「并行会话」分支（该 skill 描述的是测试场景，实际无 subagent 调度能力）
- **using-git-worktrees**：直接移除（PengTools 无 Git worktree 概念）
