设计总览与交互原则

模块边界：SQL 控制台是“连接、结构、编辑、执行”的专业工作台；模型对话是“模型配置验证与网页式通用聊天”的独立空间。两个模块共享模型配置，但不会自动共享数据库凭据、表结构、结果集、SQL 或聊天内容。
主操作：深绿普通操作：白底描边风险操作：红色描边 + 二次确认助手来源：每条消息展示配置名称与模型名

模块一：导航 14「SQL 控制台」

采用“对象树 + 多标签编辑器 + AI 助手 + 结果集”的专业布局。AI 只生成草案并写入新 Tab，手工点击执行才会连接数据库。
