PengToolsHub · 模块设计 05

发布、配置与环境管理

以“生成可核对的发布材料”为边界，围绕需求范围、系统归属、SQL 校验和导出结果组织流程。界面帮助用户减少遗漏，但不在本模块直接连接或变更生产环境。

页面布局

采用“主工作区 + 发布概览侧栏”的结构：主区负责完成选择与预检，侧栏持续显示本次范围和待处理风险。页面不堆叠配置表单，系统与环境维护转入资源型页面或弹窗。

01 · 上线范围

上线日期、候选需求、系统/关键字筛选和批量勾选。

02 · SQL 汇总

按系统分组预览，清楚标记缺失归属、空 SQL 与格式问题。

03 · 发布前检查

用通过、需确认、阻断三类结果代替散乱弹窗。

04 · 导出材料

生成 23 列发版 Excel 与按系统分隔的 SQL，反馈产物位置。

一级页面

发布准备

默认页。顶部固定日期与目标范围，中央展示候选需求列表和预检结果，右侧汇总本次系统、需求数和待确认项。

发布记录

按日期、系统、结果检索已生成的本地材料；用于回看和复用，不承担远程执行、回滚或线上状态监控。

系统配置

以列表展示系统名称、开发/生产地址、SID、目录模板和 SSL 规则。新增、编辑、删除均在弹窗中完成。

导入 / 粘贴 SQL

作为独立工作入口，可导入或粘贴 SQL 并做轻量检查、预览和归属确认，再回到发布准备流程。

核心组件与交互

日期与候选需求

  • 默认按实际上线日期推荐，日期统一使用 yyyyMMdd。
  • 保留全选、取消选择、搜索和按系统筛选；列表仅展示本次决策必需的编号、标题、系统、完成状态、SQL 状态、上线日期。
  • 点击需求行展开右侧详情抽屉，查看完整描述、SQL 与关联材料，不离开选择上下文。

按系统汇总的 SQL 预览

  • 每个系统独立分区，显示需求数量、SQL 条数和校验结论。
  • 多系统需求必须选择额外 SQL 的归属；未归属即阻断生成。
  • 提供复制、格式化、导出预览；不在此处直接执行数据库命令。

预检结果面板

  • 通过 系统归属完整、有效系统、日期有效、表头可写入。
  • 需确认 无 SQL 需求、轻量语法警告、历史系统已删除等需要人工判断的场景。
  • 阻断 未选择需求、无有效系统、SQL 未归属、日期格式错误等不能生成的场景。

系统与环境配置

  • 主界面只有“环境配置 / 系统配置”入口，不直接平铺新增、编辑、删除按钮。
  • 配置弹窗以列表管理多个系统；编辑中明确开发与生产地址，敏感字段遵从现有本地保存策略。
  • 删除前列出仍关联的需求数量，并要求用户重新确认系统归属；不自动删除历史需求。
主操作边界：“生成发布材料”是唯一主按钮。它生成 Excel 与 SQL 文件并反馈路径，不会发起远程发布、连接数据库或修改生产环境。

发布准备流程

  1. 选择日期与范围：系统按实际上线日期推荐候选项；用户按系统、关键字筛选并勾选需求。
  2. 核对系统与 SQL：打开 SQL 汇总，按系统检查 SQL 内容和额外 SQL 归属；无 SQL 的需求必须明确确认后才能继续。
  3. 处理预检问题：右侧概览显示问题数量。点击问题可直接定位到需求、系统配置或 SQL 分区；阻断项全部解决后才启用生成。
  4. 预览与生成：生成前弹出范围确认，列出上线日期、系统、需求、无 SQL 确认项与预计文件；确认后写入标准模板与系统 SQL。
  5. 查看结果：完成态显示生成的 Excel、各系统 SQL 路径与校验摘要；可打开目录或复制路径。失败时保留已选范围和错误定位，不清空用户输入。
降低遗漏：“本次发布概览”始终显示目标日期、涉及系统、选择数量与待确认项，避免用户在长列表中丢失上下文。

响应式、安全与验收规则

桌面响应式

≥1280px 保持主区 + 300px 概览栏；1024–1279px 概览栏缩至 260px；更窄窗口将概览收为右侧抽屉。按钮保持单行，筛选工具条横向滚动，不截断关键文字。

安全与可用性

生产信息用文字标识，不以高饱和红色制造持续警报；删除系统、覆盖导出等操作必须展示影响范围并二次确认，默认焦点落在取消。全流程支持键盘操作和 WCAG AA 对比度。

验收重点

验证日期推荐、跨系统筛选、无 SQL 确认、SQL 归属阻断、模板表头、各系统 SQL 输出与失败后状态保留；内网 SVN 相关功能继续标注为待用户内网验证。
