# 需求管理：状态、进度与布局调整

日期：2026-10-29。基于本地 `main / 998d1d76e3ff25bc431e3deeeac73a3f4f35e899` 及现有未提交修改。本轮不改日志排查、OB连接，不打包、不提交。

## 使用方式

- 设置 → 外观 → 需求管理，或需求管理 → 更多，均提供两个独立入口：**任务状态配置**、**任务进度节点配置**。
- 任务状态配置维护1～32个状态及其业务分类。需求详情下拉框、节点默认状态下拉框及关联状态选择共用该列表。
- 节点配置只维护节点名称、顺序、点击后的默认状态、关联状态；最多12个节点，可全部移除。删除节点不删除任何任务状态。
- 每个状态最多关联一个节点，可暂不关联。多个细分状态可以关联同一个节点；点击节点直接切换到配置的默认状态，不再弹菜单。初始默认仍为开发→开发中、测试→集成测试。
- 业务分类只在任务状态配置中维护，用于首页统计与上线语义。节点配置中不再出现业务分类。
- 旧版合并配置只在读取时转换为独立状态和节点，保存时写入版本2；不自动写用户配置。重命名状态同步更新节点引用；删除被节点引用的状态前，需先调整关联关系。
- 旧版合并配置曾被精简为节点代表状态时，拆分读取会补齐原有十个状态：待分析、待开发、开发中、待测试、集成测试、用户测试、模拟测试、待上线、已上线、暂停；保留自定义状态。新版独立配置中主动删除的状态不会反复补回。此兼容路径与工作流相关测试共21项通过。
- 配置重命名/删除不批量改写历史需求。历史状态仍显示，并保留已知业务分类；新导入需求使用配置的初始分析状态（没有分析分类时使用首个状态）。

## 页面与导入菜单

- 状态配置窗口的行高随内容适配，最小44px；业务分类下拉框限制局部内边距，避免覆盖相邻行。已核验13/16字号下的控件边界及合成数据离屏截图。
- 顶部搜索框、三个筛选框与按钮等高；右侧状态框与编辑按钮等高。带当前主题的实际控件测量均为36px。
- 文件库“名称、路径”列伸展填充可视宽度，其余列可调整。预览中列总宽与可视区同为989px。
- 更多保留登记缺陷，并列出：通过SVN路径导入、通过需求目录导入、手动登记导入、系统配置。
- 原“导入资料”是单份文档识别，并非目录扫描。入口移到文件库更多 → 从单份文档登记需求，保留能力。

## 编辑后定位修复

根因：原树刷新逻辑只要搜索词非空就选择第一条匹配，状态保存与编辑保存均触发此逻辑。

现仅在搜索词改变时定位首条；保存时按需求ID保留当前条目，并保留同组内排序和列表滚动位置。若修改后该需求不再符合当前筛选条件，则展示其余匹配结果。进度节点修改同样适用。

## 2026-10-29 后续缺陷修复

- 测试点保存后原先只替换内存列表，未更新左侧树行的记录副本和计数；切换任务后会重新显示旧清单，继续保存可能覆盖刚添加的条目。现保存成功后就地同步树行数据和计数，保持选中任务及滚动位置。
- 新增输入仅在保存成功后清空；失败时回滚清单并保留输入用于重试。编辑器的变更通知改为保存成功后发送，共用测试点弹窗也明确处理写盘失败和需求不存在。
- 原局部高度样式未限定控件类型，误约束了下拉弹出列表。现限定为输入框/下拉框本身，验证弹出列表可显示多行。
- 节点菜单位置问题已修正，随后按用户要求取消节点菜单，改为点击直接选择默认状态；最新默认值由独立节点配置控制。
- 本次运行测试点、保存失败、工作流、需求视图四组定向测试，共47项通过。使用临时台账与离屏原生控件；未验证打包程序及用户真实数据。
