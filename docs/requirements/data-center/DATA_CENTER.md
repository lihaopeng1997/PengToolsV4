# 数据中心

目标是只读 Agent 驱动的数据库工作台：模型可以在授权范围内查元数据和有界结果，人仍然掌握连接、事务和写操作。下面写的是产品边界和已经落地的分层，不是真实引擎、真实模型或安装包的验收结论。未完成项见同目录另外三份说明。

## 范围

首版覆盖已有关系库连接上的元数据浏览、手动 SQL、只读 Agent，以及 Redis、MongoDB 的既有浏览能力向新工作台迁移。SSH 隧道使用该库连接自己的认证材料，不复用日志模块的会话。

不在首版：新数据库引擎、云账号同步、对外工具服务、外部命令行 Agent、会写库的 AI、跨库搬迁、可视化改结构，以及完整的 DBA 平台。达梦按决定延后。手动 SQL 仍按该引擎原有能力和事务规则执行，不因为 Agent 是只读就把控制台改成只能输入一种语句。

## 分层

界面、Agent 运行器和数据库驱动分开。连接配置、加密凭据和工作区历史留在本机仓库层，不把账号、密码、密钥或连接地址放进模型上下文。工具参数不接受主机、用户名、口令、连接覆盖、任意文件路径或 shell。

只读不能靠语句以某个单词开头来判断。执行前要校验原始语句和实际发出的语句。解析器不够时，还要有该引擎上可核验的只读会话或只读账号。保护落不了地时，Agent 只能出草稿，不能假装已经执行。

结果交给模型前要限行、限字节，并区分空值、空串、小数、日期和二进制。名称像凭据的字段不发送原值。这是请求边界，不是对全部敏感数据的保证。

## 运行

模型调用走增量事件：推理、正文、工具参数、用量和本轮结束。界面只在自己的线程上收队列信号。停止是协作式的：取消令牌阻止新的模型轮次和工具，正在执行的数据库语句不一定能立刻停掉。不能用强行结束线程或关掉别的标签来假装已经停止。迟到结果按代次丢掉。

同一调用反复出现且没有新证据就停止。元数据读取可以有限并行，实际数据查询串行，并复用本轮只读会话。上下文预算未知时用保守上限，不把输出额度当成上下文窗口。
