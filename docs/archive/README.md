# 历史资料

本目录保留设计演进和开发交接。它们描述各自时间点的目标、实现与限制，不能替代当前源码和已确认需求。

| 目录 | 内容 |
|---|---|
| `design/proposals/` | 早期模块设计、问题分析与改造方案 |
| `design/product-strategy/` | 历史产品方向、需求和页面设计稿 |
| `design/plans/`、`design/superpowers/` | 早期实施计划与设计规格 |
| `design/ui/`、`design/inventories/` | 历史 UI 规范与功能盘点 |
| `design/prototypes/` | 已退出当前设计入口的原型 |
| `handoffs/` | 历史版本、阶段交接与目录清理记录 |

当前入口为 [项目开发说明](../project/README.md)和 [Prism V2.1](../design/prism/README.md)。历史文档中链接到旧提交的资料不包含在当前分支；开发测试和验收材料在本机保留。
