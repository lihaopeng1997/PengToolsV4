搜索点击闪退分析

范围：JSON 查看器、XML 工作区的搜索结果导航（回车、上一个、下一个按钮）。

问题描述

输入搜索词后，用户点击搜索结果导航按钮或按回车进入下一处命中时，应用可能直接退出。实时输入阶段已不会抢走搜索框焦点，但结果导航路径仍会触发编辑器抢焦点。

根因

ui/search_highlight.py 的 apply_text_match_index() 默认会调用 focus_text_span(..., take_focus=True)，进而对折叠文本编辑器执行 setFocus()。

JSON/XML 的实时搜索已显式传入 take_focus=False；但用户主动导航命中（回车、↑、↓）时，ui/json_viewer.py 与 ui/xml_workspace.py 未传入该参数，重新回退到默认抢焦点行为。焦点切换与高亮、折叠区域展开、当前行刷新叠加时存在 Qt 控件状态竞争，造成闪退风险。

复现路径

  1. 在 JSON 查看器或 XML 工作区输入可命中的关键词；
  2. 搜索结果出现后，按回车或点击“上一个/下一个”；
  3. 导航逻辑将焦点从搜索框切到带折叠能力的编辑器；
  4. 高亮与折叠刷新同时执行时，可能触发应用退出。

拟修复方案

  • 在 JSON/XML 的结果导航路径中统一传入 take_focus=False，使搜索框在输入与命中跳转全过程都保持焦点。
  • 补充回归测试：搜索后连续点击“下一个”和按回车，不发生焦点转移或异常。
  • 定向验证后重新打包离线安装包。

影响范围：仅调整搜索导航的焦点策略，不改变搜索命中、高亮、滚动定位和快捷键行为。

结论与建议

建议按最小修复方案处理：搜索结果跳转只负责高亮与滚动，不再把编辑器设为焦点。这既规避闪退风险，也让用户可以持续搜索、连续按回车浏览结果。
