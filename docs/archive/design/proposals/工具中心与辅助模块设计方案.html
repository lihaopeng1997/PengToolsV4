工具中心与辅助模块

将分散的离线工具、需求协作、知识沉淀和个人设置组织为任务型入口：用户可以按“现在要解决什么”找到功能，而不是先记住每个模块的技术名称。

信息架构

辅助模块并不合并业务逻辑，而是统一入口、检索、详情与确认方式。保留原导航与模块边界，工具中心作为跨模块的“任务索引”，用于发现、收藏和继续处理。

排查与诊断

接口排查、日志排查、网关解密、SSH 终端。

转换与整理

格式工具、VIN、证件类型与离线数据校验。

文档与测试

SQL 到 DOCX、接口文档更新、测试样本。

协作与沉淀

需求、日报、知识库、设置与个人偏好。

导航原则：原有模块入口继续保留，工具中心不制造第二套功能；它只提供任务分类、搜索、收藏、最近使用和“继续处理”的快捷跳转。

工具中心设计

任务型分类与搜索

  • 默认展示全部工具，并按“排查与诊断、转换与整理、文档与测试、协作与沉淀”分类。
  • 支持按工具名、操作名、关键词搜索，例如搜索“格式化”“日志”“DOCX”“日报”。
  • 每个工具卡片只展示名称、一句任务描述、收藏和最近使用标识；不展示虚构运行状态或敏感内容。

收藏、最近与继续处理

  • 收藏仅保存工具入口和展示顺序，不保存输入内容、密钥、令牌或请求正文。
  • 最近使用记录默认只包含模块、时间和非敏感任务标题；支持在设置中清除。
  • “继续处理”只对可安全恢复的草稿、需求、日报、非敏感本地工作项生效。

统一“发送至”动作

  • 格式化结果可发送到格式工具；XML 可转到格式工具；SQL 可发送至接口文档更新或发布准备。
  • 需求可发送至 SQL、DOCX、日报；日志和接口排查可跳转到 SSH/终端上下文。
  • 所有跨模块转交先展示目标、携带内容类型与敏感提示；用户确认后才打开目标模块。

工具的空状态与异常

  • 首次没有收藏时，展示推荐的高频排查入口，不展示营销型引导。
  • 处理失败时保留用户输入并提供明确错误位置、复制错误信息和重试入口。
  • 离线工具不提示联网或外部数据同步，确保产品边界清楚。

辅助模块统一规范

需求管理

采用“左侧分类 / 月份树 + 中部筛选列表 + 右侧详情抽屉”布局。需求详情统一放置基本信息、SQL、DOCX、附件和 SVN 状态；检出、更新、锁定、解锁、提交、回滚继续保持明确范围提示。发布、SQL 和日报仅作为“发送至”关联，不复制对应模块。

日报与自我学习

使用同一类列表—详情—编辑模式：左侧日期或分类，中央条目列表，右侧富文本/内容编辑。日报保存、复制、提醒保留；知识导入、整理、检索保留。未保存离开时提示保存、放弃或取消。

格式工具、VIN 与证件类型

统一为“输入区 / 结果区”双栏或上下结构，结果默认更大。格式工具仅做离线转换与格式化，不执行 SQL；VIN 与证件类型只提供模拟测试数据、格式校验和明确的复制/导出动作。

网关解密与接口文档

网关解密参数始终可见，失败时不清空密钥；密钥、密文和明文仅在当前内存会话中显示。接口文档更新保留 SQL 到 DOCX 的受控流程，输出文件必须由用户选择或确认位置。

设置

采用分组设置页：外观与密度、数据与清理、连接与安全、提醒与默认行为。低风险开关可即时保存；涉及清理记录、重置配置、证书/代理恢复的操作需要影响范围说明和二次确认。

统一列表、详情与编辑

列表提供搜索、筛选、排序与空状态；详情采用可收起分区；新增/编辑使用弹窗或详情编辑态；删除、清理、覆盖操作使用危险色、二次确认，默认焦点为取消。按钮文字保持单行，不截断。

现有功能调整说明

现有能力调整后呈现变化性质
格式工具：JSON/XML/SQL/文本处理保留离线输入与结果能力，统一为输入/结果阅读区；SQL 仅格式化和整理，不新增执行能力。保留并统一布局
网关 SM2/SM4 解密、JSON 查看保留参数、解密和结果查看；敏感内容仅内存态，失败不清空密钥。保留并强化边界
VIN、证件类型测试数据保留模拟生成与格式校验；明确测试用途，导出/复制由用户主动触发。保留并澄清用途
SQL 驱动 DOCX 接口文档更新保留 SQL → DOCX 流程；通过“发送至”从需求或工具中心进入，不重复录入。保留并串联
需求：树、筛选、附件、SVN、SQL/DOCX/日报联动保留业务能力；采用统一列表/详情/编辑结构，危险 SVN 操作显示范围与确认。保留并结构化
个人知识库与日报保留导入、整理、检索、保存、复制和提醒；与需求共享“发送至日报”但不混合数据源。保留并统一交互
设置与偏好将主题、密度、提醒、数据清理、安全连接按分组聚合，立即生效或确认后保存。保留并聚合

数据边界、响应式与验收

严禁进入历史、搜索索引、收藏或日志的数据：网关密钥、密文与明文；接口抓包中的 Authorization、Cookie、Token 和请求/响应敏感内容；真实证件号；工作簿密码；SSH 明文密码及含凭据的知识内容。SSH 凭据仅按既有用户授权与加密策略保存。
桌面响应式

≥1280px 工具卡片三列；1024–1279px 两列；更窄窗口为两列或一列，并将筛选收进抽屉。关键输入与结果不因窗口缩窄被隐藏，按钮文字单行显示。

一致性与可访问性

搜索、筛选、列表、详情、编辑、空状态、进度和危险确认使用统一组件；最小点击区域 44px，键盘焦点清晰，文本与背景达到 WCAG AA 对比度。

验收重点

验证所有工具仍离线、SQL 不被执行、敏感数据不写入配置或历史；验证跨模块“发送至”需确认、需求 SVN 状态不丢失、日报提醒复用设置、删除/清理默认取消。
