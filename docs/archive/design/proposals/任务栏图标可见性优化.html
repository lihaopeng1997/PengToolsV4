任务栏图标可见性优化

PengToolsHub · 黑色 Windows 任务栏图标不可见问题分析

问题描述

黑色 Windows 任务栏下，PengToolsHub 图标对比度不足，难以识别或看起来接近不可见。

关键发现

运行时与发布内嵌图标不一致，是本次问题的直接根因。run.py 已优先使用高对比 pengtools-taskbar-hc.ico；但发布脚本和主 PyInstaller 规格仍将 EXE 内嵌图标设为 pengtools-app-v2.ico。Windows 在任务栏固定项、分组或图标缓存场景下可能优先读取 EXE 内嵌图标，因此没有稳定使用高对比版本。
  • 高对比图标资源已存在：浅色圆角底 + 深墨绿标志，设计上适用于黑色与浅色任务栏。
  • 运行时窗口图标已优先使用该资源，应用内部窗口与新启动实例通常正常。
  • 打包入口 scripts/build_release.ps1 的 --icon 仍指向绿色品牌 ICO。
  • 根目录 PengToolsHub.spec 的 EXE 图标也仍指向绿色品牌 ICO。

拟修改方案

将 scripts/build_release.ps1 的 PyInstaller --icon 改为 resources\brand\pengtools-taskbar-hc.ico。
将 PengToolsHub.spec 的 icon 同步为高对比 ICO，避免手动用 spec 打包时回退到旧图标。
保留 run.py 当前的高对比优先逻辑，不改动主题、侧栏品牌或托盘的现有行为。
执行定向语法检查与离线打包，核验新 EXE、Installer 目录和 ZIP 安装包均已刷新。

影响范围与预期效果

改动文件scripts/build_release.ps1、PengToolsHub.spec 不受影响功能逻辑、主题切换、侧栏图标、系统托盘交互与用户数据。 预期效果新打包的 EXE 在黑色和浅色任务栏上均采用高对比、带浅色底板的应用图标。

注意：Windows 可能缓存已固定到任务栏的旧图标。安装新版后，如任务栏仍显示旧图标，只需将旧固定项取消固定，再从新版 EXE 重新固定；不需要清理系统图标缓存。

结论与建议

建议执行上述两处图标源统一修改并重新打包。这是最小且可验证的修复，能让运行时、EXE 内嵌图标和任务栏固定项使用同一套高对比资源。
