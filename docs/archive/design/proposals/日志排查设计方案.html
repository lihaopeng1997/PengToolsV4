日志排查设计方案

定位为“从目标定位到结论导出”的连续排障工作区：左侧负责选择目标和定义查询，右侧默认最大化展示带上下文的命中日志，并随时可转入当前会话终端。

页面布局

顶部：模式与管理入口“会话排查 / 批量导出”作为一级切换；服务器管理和排查设置置于右侧。并发、超时、默认上下文行数等低频设置不抢占检索区域。
左侧：目标与日志按服务器、服务、日志文件三步确定目标；默认推荐最新日志，同时明确提供“切换日志文件”和远端文件树，避免只能看最新文件。
左侧：检索条件关键词输入、多关键字 AND 规则、上下文行数、忽略大小写与开始检索形成连续区域。规则说明始终可见，减少多关键词误解。
左侧：远端文件保留上级、刷新、打开目录与目录树，双击可进入或选用具体日志。目录操作只刷新当前会话上下文，不影响其他 SSH 标签。
右侧：结果主阅读区固定展示当前服务器、服务、日志路径与连接状态；结果、异常摘要、终端三个标签中，默认“命中结果”占据最大空间，支持行号、高亮和上下文。
底部：导出与结论左侧显示单机与批量导出进度、成功/无命中/截断等明确状态，右侧输出异常关键字和次数摘要，可复制或保存非敏感排查记录。

核心组件

  • 目标选择器：服务器、服务、日志文件依次呈现；已连接状态使用文字与图形，连接失败提供明确下一步，不仅显示颜色。
  • 关键词编辑器：支持逗号、分号、换行输入；首项主条件，其余为 AND；检索前拦截非法换行路径和不安全参数。
  • 日志结果：等宽字体展示行号和原始文本；命中词高亮、WARN/ERROR 使用语义色，保持复制和完整上下文阅读。
  • 异常摘要：仅从本次结果提炼关键词、次数和可见调用线索，不以“智能判断”替代原始日志内容。
  • 导出状态：成功、无命中、截断、失败分开呈现；无命中属于成功结果，不能误标为导出失败。

交互流程

  • 单次排查：选服务器 → 选服务 → 选最新或指定日志 → 输入关键词 → 设置上下文/大小写 → 开始检索 → 查看命中和异常摘要 → 导出或在终端继续。
  • 目录定位：打开远端目录 → 双击进入目录或选中具体文件 → 回填当前日志文件 → 继续检索；不需要离开当前排查页。
  • 终端联动：点击“在终端打开”将当前会话的主机、服务和日志路径带入独立终端标签；终端处理不会清空当前结果。
  • 批量导出：切换批量导出 → 按分类/服务器/服务树勾选目标 → 可逐项指定日志文件 → 选择本地目录 → 执行并行流式导出 → 查看每项结果。

现有功能调整说明

现有能力调整后的展示/操作保持不变
会话 / 批量导出模式提升为顶部一级切换，切换后左栏替换为目标树和导出规则。单机与多机多服务导出能力。
主机、服务、日志路径/文件整理为“目标与日志”三步选择，当前路径固定显示在右侧上下文条。服务器分类、每机多服务、最新日志推荐与指定文件选择。
关键字、上下文、忽略大小写集中于检索条件区，增加 AND 规则说明。逗号/分号/换行分隔，首项主条件、其余 AND，0–200 行上下文。
预览、看尾部、终端截取“开始检索”是主操作；看尾部和终端截取作为同组次级操作。现有 grep、tail 与终端输出能力。
远端目录保持在左栏下方，含上级、刷新、打开目录与文件树。目录浏览、日志候选和按修改时间选最新。
导出/批量导出进度与结果收敛到右侧底部，减少弹窗打断；可直接打开导出目录。关键字文件夹 / IP-服务.log 命名、查询元信息、无命中成功、并发/大小限制。
右侧终端作为结果区的独立标签与“在终端打开”入口，不再与结果抢默认空间。最多4标签、连接 per-tab、终端退格和输出限流。

响应式与安全约束

  • 宽屏：左栏建议 280–300px，右侧结果区占至少 65%；底部导出与摘要并列。
  • 1024px 至 1279px：左栏压缩但保留全部目标字段，顶部按钮可横向滚动且文字不换行。
  • 小于 1024px：左栏作为可隐藏抽屉；结果区和当前上下文持续可见；导出和摘要纵向堆叠。
  • 密码使用 DPAPI/enc 加密，禁止明文或新增 b64；日志经 SSH stdout 流式读取，禁止写远端临时文件；单机导出 80MB 截断、并发 1–16、超时 5–300 秒的既有保护必须保留。
  • 导出路径必须解析到具体 .log 文件，且每标签连接隔离；关闭或断开一个会话不得影响其他标签。
