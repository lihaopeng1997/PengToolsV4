# PengToolsHub V4.27.5 Private 发布说明

**构建时间以 `resources/build_info.json` 为准。**  
产物：`PengToolsHub_Offline_Setup.zip`、`dist\PengToolsHub\`（含 `PengToolsHub.exe` 与 `_internal\` 运行时目录）。

## 本期核心能力与更新

- **工作台与视觉**：单一晴空棱镜（`calm`）主题、V5 Prism Fold 全套品牌图标（主 Logo / 9 档高清任务栏与托盘 ICO / 悬浮球）、左右悬浮双卡工作区、首页「简洁 / 完整」双视图及与日报的实时双向同步。
- **启动更新公告**：升级后首次启动自动提示新版更新亮点，支持勾选「本次更新不再提醒」或「永久关闭弹窗」，也可随时从顶部「帮助 → 更新公告」查看历史版本。
- **统一数据中心**：Oracle、MySQL、OceanBase、达梦、Redis、MongoDB 统一连接与工作区，带 SQL 安全守卫与 AI 辅助。
- **智能助手**：内网模型聊天（流式输出、会话隔离）与 Agent 工作台（受控工具与项目上下文）。
- **交付闭环**：需求管理（台账/流转/测试点/文件库）→ 发版联动（自动生成 SQL 与目录/提签）→ 接口文档更新 → 按月归档富文本日报。
- **运维与开发**：日志排查（多机 SSH 终端 + 独立底部命令坞 + AI 只读排查）、命令库（119+ 运维与 JVM 命令）、接口排查（本机抓包 + 请求测试）、格式工具（JSON/XML/SQL/文本 + **图片/PDF ↔ Base64 离线双向互转**）、合并式「测试数据」（证件类型 + 车辆 VIN）。
- **引导与效率**：10 大核心模块交互式聚光灯新手引导、`Ctrl+K` 离线拼音与别名全局搜索、悬浮工具栏快捷入口与便携 AI 对话。

> 详细变更记录见仓库根目录 [CHANGELOG.md](../../CHANGELOG.md)。

## 使用边界（分发时需同步告知）

- 纯离线桌面工具，无账号体系、无云同步、无在线自动升级；数据仅保存在程序同级 `data/` 目录。
- 「测试数据」生成的证件号、企业信用代码、VIN 与车牌均为**模拟测试数据**，严禁作为真实业务证照使用。
- 接口排查代理严格限定本机 `127.0.0.1`，停止抓包后自动恢复系统代理；抓包会话默认驻留内存。
- SVN 检出/提交、内网数据库驱动（如 Oracle Thick / OceanBase ODBC）及内网模型接口需在目标内网环境按实际权限验证。

## 安装与升级

1. 解压 `PengToolsHub_Offline_Setup.zip`，运行 `setup.cmd` 或直接进入 `PengToolsHub\` 启动 `PengToolsHub.exe`。
2. 程序依赖同级 `_internal\` 目录，**切勿单独复制 `PengToolsHub.exe`**。
3. 覆盖升级时**务必保留原有 `data\` 目录**（升级前建议备份 `data\`）。
4. 若 Windows 任务栏仍缓存旧版图标，重启资源管理器或换新目录解压即可刷新为 V5 新图标。
