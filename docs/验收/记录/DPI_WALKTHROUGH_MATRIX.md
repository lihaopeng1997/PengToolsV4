# PenngTools V4 UI 真机走查矩阵（P2）

本文件记录必须人工验收的 DPI / 分辨率矩阵。自动化 `classify_layout()` 断点测试不能替代本表。

## 窗口与 DPI

| 分辨率 | DPI | 布局档 | 必看页面 | 通过标准 |
|---|---|---|---|---|
| 1440×900 | 100% | Wide | 工作台 / 需求 / 接口排查 / 日志SSH / SQL | 三栏可读，主操作不截断 |
| 1280×800 | 100% | Standard | 同上 | Splitter 可拖，双击可复位 |
| 1100×720 | 100% | Compact | 接口排查请求验证、SQL、日志SSH | 次要按钮进更多/收纳，两行验证仍完整 |
| 960×640 | 100% | Narrow | SQL / 日志SSH / AI 助手侧栏 | 真回退（上下或显示目录/助手开关），不是只藏副标题 |
| 1440×900 | 125% | — | 接口排查、日志终端 | 字体/控件不重叠，HTTPS+发送同一行仍可用 |
| 1440×900 | 150% | — | 需求文件库九按钮、SQL 执行 | 横向可滚，主按钮可点 |

## 动效边界

- 允许：120–180ms hover/focus；Tab 轻抬升；Loading 浮层
- 禁止：高频呼吸、扫描线、全局毛玻璃、页面转场动画
