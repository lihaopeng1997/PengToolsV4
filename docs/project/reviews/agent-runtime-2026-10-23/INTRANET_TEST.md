# R3 内网复测（2026-10-23）

## 使用哪个包

使用 `PengToolsHub_Agent_20261023_R3.zip`，不要用前一份 `AgentFix` 包。

1. 退出旧版软件，将新包解压到一个新目录；保留旧目录便于回退。
2. 如需复用配置，在内网本机备份并复制旧版 EXE 同级 `data` 到新目录。不要把 data 发出内网；换 Windows 账号时加密凭据可能需要重新填写。
3. 运行新目录的 EXE；新日志版本应为 `agent-20261023-v3`。单实例行为可能使未退出的旧版被再次激活，务必核对。

## 依次检查

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| Oracle / OceanBase 查数 | 扫描结构，选择业务 Schema，选“Agent · 只读查数”，要求查找一张授权测试表并统计 | 实际出现元数据/查询工具步骤和结果，不只是给 SQL；跨 Schema 请求应被拒绝或要求换范围。 |
| Redis | 打开统一 AI 入口，输入“查找包含 sys 的 key” | 使用 redis_read 的 SCAN 获取结果；不再进入旧的命令生成框；未扫描完应说明当前只得到部分结果。 |
| 连续对话 | 查完后问“继续解释刚才结果”；再新建对话 | 同一范围内保留上下文，新建对话清空。切换 Schema 后下一轮使用新范围，不沿用旧范围结果作为当前查询证据。 |
| 输入与滚动 | Enter 发送，Shift+Enter 换行；输入法选词；翻看旧回答后等待新内容 | 不误发输入法组合文本；发送后看到新消息，手动翻阅时不被强制拉走。 |
| 写代码 | 在测试目录要求新增、修改、删除一个测试文件；先拒绝，再批准 | 未批准前无写入；读取/搜索不弹确认。项目测试会执行代码，需确认后才运行。 |
| 长任务 | 连续分析多个文件，观察上下文状态；发生超时后发送“继续” | 接近 400 KiB 时自动规划压缩，原记录保留；已完成步骤可从记录继续。 |
| 右键 | 在知识内容查看区和 AI 输入框点右键 | 中文复制所选、复制全部、全选；可编辑区提供剪切、粘贴、撤销等。 |
| 停止 | 模型等待或生成时停止 | 界面响应，显示取消/结束状态，不在取消后执行尚未批准的修改。 |

如果模型首个响应很慢，可在模型高级设置调整“Agent 连续无响应超时”（默认 60 秒，上限 600 秒）；“Agent 单轮最长时间”默认 600 秒，上限 3600 秒。500 KiB 是本机请求字节额度，不是服务端 token 窗口。`仅文本` 配置不执行查询；只有明确要草稿时选择 Ask 模式。

OceanBase 需匹配实际租户模式；Oracle 模式仍需目标机现有驱动支持。
