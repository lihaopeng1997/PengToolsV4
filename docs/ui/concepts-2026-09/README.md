# PengToolsHub 首页 UI 设计提案

2026-09-07。单模块概念设计：**首页工作台 + 软件导航外壳**。三个版本使用相同的示例上线任务、测试点、上线进度和工具入口，重新组织布局与视觉。没有修改正式应用、真实数据或配置。

## 打开

双击 `index.html` 查看三个方向。也可单独打开 `aurora.html`、`prism.html` 或 `ion.html`。请保留同目录下的 `dashboard.css` 与 `dashboard.js`；无网络依赖、外部字体、CDN 或在线图片。

| 方向 | 布局 | 视觉 | 取舍 |
| --- | --- | --- | --- |
| 01 极光玻璃 | 完整左侧导航，焦点 + 指标，任务 + 上线总览，底部工具 | 午夜蓝、薄荷青、淡紫，半透明外壳与轨道装饰 | 综合推荐，功能可发现性和年轻科技感平衡 |
| 02 晴空棱镜 | 图标导航，左侧主内容，右侧进度与工具 | 冰白、薰衣草紫、青色柔光，磨砂玻璃 | 更明亮轻盈；图标入口用悬浮名称和快捷搜索辅助识别 |
| 03 离子控制台 | 横向主导航，左侧焦点，中央详细任务，右侧上线总览 | 石墨灰、电光绿、烟色玻璃，较小圆角 | 个性更鲜明；窄屏将辅助面板移到下一行 |

## 可以体验的交互

- 四种上线任务状态筛选、展开全部 12 项、任务详情与测试点。
- 勾选任务完成 / 取消完成，同步更新本月完成数、累计完成和月度进度圆环。
- 测试点逐项确认，自动更新任务进度与测试点总数；所有测试点通过后才可确认上线完成。取消已完成任务的某个测试点，会撤销完成状态。
- 新建示例上线任务并更新本月总量。空名称与纯空格不能提交，用户输入按文本展示。
- 编辑日报，暂存后更新本周日报计数；重复保存不会重复增加。
- Ctrl/Cmd + K 搜索工具与示例上线任务，空结果反馈；Tab / Enter / Esc 操作。
- 上线清单展开与常用工具介绍弹窗。
- 外观弹窗切换设计方向、关闭装饰动效。自动跟随 `prefers-reduced-motion`。
- 概览页切换 1440 / 1280 / 960 布局宽度，用实际页面缩略预览比较。

新建任务、完成标记、测试点与日报只保存在当前页面内存，刷新即恢复。工具入口展示说明，未连接数据库、SSH、模型或真实业务。

任务进度为原型规则：开发就绪 25%，测试点 65%，手动确认完成 10%；不代表当前业务已有该算法。用户确认后，正式实现需要再对齐业务进度定义。

## 技术栈与落地边界

本次已检查当前分支 `review/correction-round-4`，开始时工作区干净。依据当前源码：

- `requirements.txt`：Python 3.12 发布基线、PyQt6、Qt WebEngine。
- `frontend/package.json`：Vue 3.5.42、TypeScript 6.0.2、Vite 8.2.2。
- `frontend/src/dashboard/DashboardApp.vue` 和 `types.ts`：欢迎区、需求统计、日报、月度上线、最近需求、工具导航。
- `ui/navigation_model.py`：使用现有中文模块名称和职责。
- `ui/layout_metrics.py`：1440 / 1280 / 1100 / 960 分档，桌面最小画布 960 × 640。
- `ui/theme_manager.py`：正式应用主题唯一入口。

原型中的配色变量仅服务于设计方案比较。确认方案后，应该将选中的颜色映射回 ThemeManager 语义 token，并在 Vue 中拆分外壳、导航、指标、上线任务列表、上线总览面板和工具入口，通过既有 QWebChannel Bridge 注入数据。正式 Vue 源码变更时需要同步生成嵌入资源。

数据库、SQL、SSH、文件操作等复杂工作台仍依据当前架构使用 PyQt；本次没有改变这些边界。玻璃质感来自网页内部背景与面板叠加，不代表已经实现 Windows 原生透明窗口。列表文字下使用稳定底色，装饰层仅做轻微移动。小于 960px 的重排为预览便利，不改变桌面应用最小尺寸约定。
