# PengToolsHub 晴空棱镜 UI 优化需求与 Agent 实施规范

版本：1.1 · 2026-09-08 · 状态：设计交付，待用户视觉审阅。

## 0. 最高优先级：只处理 UI

用户最终约束：**结合当前功能，只做 UI 处理，不改变现在的功能逻辑。** 本文的尺寸、色彩、排布、图标与动效是目标设计；当前仓库的业务函数、权限、输入输出、持久化、信号与槽是行为权威。HTML 中的假数据及模拟处理不是业务规范。

允许：样式、布局容器、间距、字体、SVG、视觉状态、响应式重排、只读日期/经典句展示。允许将同一个已有动作接到新的按钮位置，但参数、次数、启用条件、回调、结果必须一致。

禁止：改数据库语句及事务、补充业务校验、改完成规则、改排序/过滤口径、改变默认配置、增加导出/写入、修改网络请求与捕获策略、模型调用/线程/停止机制、隐私解锁、启动/退出/托盘生命周期。不得为原型造新 API 或把模拟成功消息带入生产。不得用重建页面销毁用户正在编辑的文本、SQL、连接或会话。

如设计入口在当前代码中不存在：记录“视觉设计保留，当前无功能入口”，隐藏或说明不可用；保持已有跳转。不要自行补功能，也不要把已有可用功能禁用。

## 2. 坐标体系与基准画布

所有值为逻辑像素（Qt DIP / CSS px），不是屏幕物理像素。原点是**软件客户区左上角**；不包含操作系统外部阴影，也不包含 HTML 顶部“设计预览”提示条。100%缩放使用下表验收；125%/150%/200%交由 Qt DPR/WebEngine 正常缩放，禁止手工重复乘 DPR。

目标基准：W=1440，H=900，默认图标导航 N=84，边距 P=24。坐标仅供验收，实际使用布局容器和伸缩约束，禁止给每个 QWidget setGeometry 固定屏幕位置。

## 5. 首页专属要求

首页使用 C=1308：左列 L=C-330-16=962，右列330；左起(108,244)，右起(108+978=1086,244)。hero高176；统计卡y=436、高108，4等列宽(L-36)/4=231.5、gap12；任务卡y=560，padding20，头32、筛选32、行64。右栏总览高300，常用工具top=560，两列格子gap8、高64；剩余文案按自然流向下。高度不足允许页面滚动。

Hero内文字起点(132,268)，最大可用宽L-180；图形盒120×120，右24、垂直居中。主标题26/34；日期经典句在标题下8，13/22，最多两行且不遮挡图形。句长时自然换行，不截去作者信息的唯一入口。

### 5.1 动态图标

- 主棱镜图形：4.8s ease-in-out循环，translateY 0→-5→0、rotate -5→5→-5度、scale 1→1.04→1。仅transform/opacity，不移动布局盒。
- 统计图标：5s周期，仅80%–100%段产生2px上浮归位，四张错开0/.3/.6/.9s；常用工具只在hover/focus时上浮2px、旋转-6度、200ms。
- 禁止所有图标同时高速旋转、连续闪烁、装饰音效；后台页暂停；页面卸载清理监听和计时器。
- prefers-reduced-motion及已有动效关闭设置必须停止循环与位移动画，静止后语义完整；不新建持久化设置键。

### 5.2 星期后的每日经典句

格式：“9 月 8 日，星期二 · 经典句”。日期来自本地日历，句库是随包分发的公共领域经典文本，不请求每日一句服务、不使用AI。展示层独立于业务统计月份，不把当前日期强加到任务月份。

当前预览包含12句，涵盖进取、积累、友情、闲适和自然。按本地年月日构造日序号并取模；同一天刷新保持一致，跨日切换，12天循环。旁边28×28换一句按钮仅改变当前页面句子偏移；不写配置、不影响业务。作者/作品用tooltip或可访问说明。显示60秒检查一次日期、页面恢复可见时立即更新；不要60秒随机换一句。生产组件卸载清理计时器。

句库见 model.js 的 DAILY_QUOTES（12条完整文本和出处）。已查阅参考：[行路难](https://www.gushiwen.cn/mingju/juv.aspx?id=4a21691b5041)、[千里之行出处](https://www.ccdi.gov.cn/yaowenn/202112/t20211210_157589.html)。其他条目为公共领域常见诗文，实施时逐条校对原文，不追加未经核对的现代作者名言。

### 5.3 月度任务

保留当前monthly_release_tasks、actual_release_date、test_points等字段的含义与原始完成规则。卡片可改变布局；不新增“所有测试点必须通过”门槛。当前Bridge没有直接完成写入接口，首页按已有openRequirement(id)进入现有编辑流程。若当前原生控件已有完成操作，则原样复用。进度、空值、示例标记按当前生产数据源展示，不能沿用HTML的12项/9项硬编码。

## 6. 单图标悬浮窗（必须）

收起态仅一个品牌按钮。原生52×52外框，按钮(4,4,44,44)，图标居中30×30，圆形；无外露快捷图标、抓手、更多按钮、文字胶囊。可选hover阴影增强，不改变屏幕锚点。点击/拖动/展开收起/置顶/越界修正全部复用QuickPanel原逻辑。

工具展开宽300、聊天340×440、学习360沿用源码；头48、尾40、卡片58、grid gap8、padding12。2列工具格宽(300-24-8)/2=134；行高58。聊天输入沿用已有大小/伸缩，不改任务线程。工具面板需完整容纳原有快捷入口及提签/学习等已可见功能，不因缩成图标删除功能。

位置是屏幕availableGeometry下的锚点，不等于主窗口客户区。多显示器存在负坐标；不得夹取到全局0。沿用_compact_position、展开方向与屏幕边界算法；拖动不误触发点击，展开/收起前后品牌中心不变。候选项、最多6项、私有解锁、默认顺序都来自navigation_model。HTML使用6px拖动阈值仅是模拟，不覆盖Qt现有判断。

## 9. 图标资产规范

统一24×24 viewBox，描边1.6，round端点，currentColor；导航20、工具18、密集16、品牌16/24/32/48/64。图标外形可优化但图标角色从navigation_model/icon_role取值，不能按菜单位置推断业务。SVG不得含外链、脚本、嵌入字体。原生需要QIcon时用已有资源加载方式生成正确DPR缓存；不添加联网下载。
