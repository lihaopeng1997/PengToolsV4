**参与成员**：方向明（产品舵手）、析客（需求分析师）、瑞思（用户研究员）、竞析（竞品分析师）、数析（数据分析师）

## 📌 TL;DR（执行摘要）
- 已对 15 个常显页面执行源码、运行态与小窗口（960×640）三层核验；业务 Tab 页签均已有可见文字，具名业务按钮均具备文字或 Tooltip，但高风险动作的“对象、目标、影响范围”仍有文案缺口。
- 当前不能认定为“全部合格”：无本地配置时，工作台、设置、日志排查、SQL 控制台、模型对话共 7 个关键下拉框呈现空白；用户无法理解需先做什么。
- 960×640 下，工作台“更多工具”、升级准备“保存当前配置”、日报“带入昨日计划/复制 Markdown”等文本存在被压缩或截断风险；接口排查、日志排查的图标按钮依赖 Tooltip，需纳入强制验收。
- 最高优先级新增发现：接口敏感内容提示与会话生命周期不一致、抓包 CA 证书信任后果说明不足、真实请求/终端命令发送的目标环境不明确，以及删除 SQL 连接未告知会同步删除本地结构快照。
- 建议将本报告的 P0/P1 条目写入后续 UI 总需求文档，并由代码实施方逐页落实；本轮未修改任何源码。

### 1.2 实际核验动作

1. **源码检索**：检查 `panels/*.py` 中 `QPushButton`、`QToolButton`、`QComboBox`、`QTabWidget`、菜单、空状态和确认文案的声明与多语言回填。
2. **运行态扫描**：在离屏 Qt 环境启动主窗口，逐页扫描可见控件；核对空按钮/无 Tooltip、空下拉、空页签。
3. **尺寸复核**：在 1440×900 与 960×640 两个窗口下复核页面；小窗口额外检测按钮宽度是否不足以容纳文本及基础留白。
4. **设计评审**：按“动词 + 结果对象”“草稿/复制/执行/删除分层”“纯图标必须可发现”“筛选下拉必须有空态或复位项”核查。

### 1.3 结论边界

- 本报告验证的是当前运行态和源码中**可见文字的存在性与可发现性**，不是对每个弹窗、动态菜单、英文文案或真实生产数据状态的穷尽式人工可用性测试。
- 原生 Qt 内部控件（如日历上/下月箭头、Tab 滚动箭头、表格角按钮）出现无文字不计入业务文案缺陷；其为框架内部导航控件。
- 不能用“未扫描到空文字”证明文案语义一定正确；高风险动作仍需通过实际任务走查验证。

## 2. 核验结果总览

| 检查项 | 结果 | 结论 |
|---|---|---|
| 15 个常显页面的业务 Tab 页签 | 通过 | 运行态未发现空白业务 Tab；SQL 升级页、预览页等先以空文本创建、后在 `set_language()` 回填，最终显示正常 |
| 具名业务按钮的文字/提示 | 基本通过 | 所有具名业务按钮均有文字，或为日志页刷新类图标按钮提供 Tooltip |

## 3. P0：必须进入全套 UI 需求文档的缺陷与修复要求

### P0-00：安全提示与实际行为必须一致

| 编号 | 页面 / 控件 | 当前风险 | 必须修订的文案与交互 |
|---|---|---|---|
| A01 | 接口排查：显示敏感内容确认 | 当前文案称“停止监听后清空”，但项目约束是停止抓包后保留会话，仅“清空”或应用退出清除 | 固定改为：“将显示 Authorization、Cookie、Token 等敏感字段。仅在当前应用会话中显示；完成后请使用「清空会话」移除。”确认默认焦点保持“取消” |
| A02 | 接口排查：安装抓包证书 | 未说明将让当前 Windows 用户信任本机抓包 CA、可解密 HTTPS 流量以及何时移除 | 明确提示：“将在当前 Windows 用户的受信任根证书库安装本机抓包 CA，使 IE HTTPS 流量可被本机抓包解密；仅在授权排查期间安装，结束后使用「移除本机抓包证书」。”确认按钮为“安装并信任证书” |
| A03 | 接口排查：请求测试发送 | 主按钮“发送”不展示请求目标、环境和认证携带状态 | 已选环境时动态显示“发送到 {环境名}”；无环境时显示“选择环境后发送”并禁用。确认框首行固定呈现“方法 + URL + 环境名 + Host + 认证状态” |
| A04 | 接口排查：请求库删除/清空 | “已保存”和“发送记录”两种模式下仍使用泛化“删除/清空历史”，无法判断范围 | 已保存模式用“删除已保存接口 / 清空已保存接口”；发送记录模式用“删除发送记录 / 清空发送历史”。确认框必须展示模式、数量、分类/搜索范围，并声明“不影响抓包会话” |
| A05 | 日志排查：终端命令发送 | “发送”未明确会把命令交给当前 SSH 终端执行 | 改为“执行到当前终端”或“发送并执行”；未连接时禁用并提示“请先连接本会话”；Tooltip 体现目标主机/会话和本机历史记录 |
| A06 | SQL 控制台：删除连接 | 删除连接同时会删除本地结构快照，但确认仅称“删除该连接” | 标题改“删除连接「{名称}」及本地结构快照？”；正文说明“不删除数据库对象，但会移除本机连接配置、凭据引用与结构快照”；确认按钮“删除连接和快照” |

**验收标准**
- [ ] 所有安全提示必须与真实数据生命周期、执行路径和恢复行为一致；不得以过期/错误口径弱化或夸大影响。
- [ ] 远端网络、SSH、证书、删除、清空操作的首屏文字与确认框都必须指出对象、目标/范围、是否可恢复及下一步。
- [ ] 所有危险确认弹窗的取消在左、确认在右，默认焦点保持取消；确认按钮使用明确动词短语。

### P0-01：无本地配置时，下拉框不能呈现空白

**问题**：当前在没有本地数据或未完成配置的情况下，多个 `QComboBox` 显示为空白，用户不能从控件本身识别“没有数据”还是“尚未选择”。

| 页面 | 控件 | 当前运行态 | 影响 | 目标文案 / 行为 |
|---|---|---|---|---|
| 工作台 | `release_month_combo` | 空白；Tooltip 为“选择要查看的上线月份” | 无发版数据时，月份筛选没有状态含义 | 显示“暂无上线月份”并禁用；或显示“选择上线月份”且提供无结果说明 |
| 设置 | `ai_model` | 空白、无 Tooltip | 用户未探测模型列表时，不知道应先填写/探测模型 | 显示“请先探测可用模型”；禁用或保留可输入说明，并在附近显示前置动作 |
| 日志排查 | `server_combo` | 空白、无 Tooltip | 无服务器时无法判断从哪新增或管理 | 显示“暂无服务器，请先管理服务器”；提供或关联“管理服务器”入口 |
| 日志排查 | `service_combo` | 空白、无 Tooltip | 未选服务器时服务选择器没有上下文 | 显示“请先选择服务器”，未选择前禁用 |
| 日志排查 | `log_file_combo` | 空白；已有日志 Tooltip | 未选目录/未刷新时仍缺主状态 | 显示“请先选择日志目录”或“暂无 .log 文件”，并保留现有 Tooltip |
| SQL 控制台 | `conn_combo` | 空白、无 Tooltip | 未建连接时对象树与编辑器上下文不明确 | 显示“请选择或新建连接”；连接列表为空时引导“新建连接” |
| 模型对话 | `model_combo` | 空白、无 Tooltip | 未配置模型时发送能力语义不清 | 显示“请先在设置中配置模型”；发送按钮同步说明不可用原因 |

**验收标准**
- [ ] 任一无数据下拉框必须显示可读的空态文字，或被禁用且紧邻给出原因与下一步。
- [ ] 如果控件依赖上级选择，上级未满足时显示“请先选择 X”，而不是空白。
- [ ] 如果空态需用户创建配置，必须提供可达的“新建/管理/配置”入口，不强迫用户记忆导航路径。
- [ ] 空态文案随中英文切换同步翻译；不能把内部 ID 或异常文本展示给用户。

### P0-02：960×640 下禁止裁切关键按钮文字

**问题**：在 960×640 运行态计算中，以下按钮宽度小于其文案宽度加基础留白，存在截断、难辨认或点击目标不足的风险。

| 页面 | 当前按钮 | 检测到的风险 | 设计/实现要求 |
|---|---|---|---|
| 工作台 | `更多工具` | 宽度约 41px，小于文字约 48px | 窄屏改为“更多”+ Tooltip，或保证“更多工具”完整显示；不得半截省略 |
| 升级准备 | `保存当前配置` | 宽度约 62px，小于文字约 72px | 保留完整“保存当前配置”，或收纳到“更多”菜单中；禁止显示成不可读缩略词 |
| 日报 | `带入昨日计划` | 宽度约 72px，接近文字自然宽度 | 在窄屏改为“带入昨日”并配 Tooltip“带入昨日计划”，或收纳；操作结果需明确不会覆盖已写内容 |
| 日报 | `复制 Markdown` | 宽度约 72px，远小于文字约 132px | 不得截断；优先改为“复制”+ Tooltip/菜单项“复制 Markdown”，或让按钮完整显示 |

**验收标准**
- [ ] 960×640、125% DPI 下，所有可见文字按钮须完整显示，或按响应式规则收纳为“更多”菜单。
- [ ] 若改为纯图标，必须提供 Tooltip、可访问名称与可键盘聚焦；不得以仅缩小字体解决拥挤。
- [ ] 文本按钮不得显示半个字、无语义缩写或换行造成按钮高度异常。
- [ ] 收纳后菜单项使用完整动词短语，例如“保存当前配置”“复制 Markdown”。

### P0-03：危险/外发/执行动作必须在文字上区分层级

**问题**：产品同时存在生成草稿、复制、真实请求测试、执行只读查询、清空会话、删除配置、导出本地文件等动作。若使用泛化动词（如“执行”“发送”“清空”），易造成用户误解影响范围。

**强制文案规则**

| 操作类别 | 文案规则 | 示例 |
|---|---|---|
| 仅生成、不发送 | 使用“生成 + 产物 + 草稿/预览” | “生成 cURL 草稿”“生成 SQL 预览” |
| 本地复制 | 使用“复制 + 对象” | “复制响应正文”“复制明文”“复制 Markdown” |
| 真实网络/远端操作 | 使用“发送/执行 + 对象 + 目标提示” | “向测试环境发送请求”“执行只读查询” |
| 本地导出 | 使用“导出 + 对象” | “导出会话明细”“导出当前日志” |
| 清空/删除/覆盖 | 使用“清空/删除 + 对象”，确认框展示影响范围 | “清空本次会话”“删除当前服务器配置” |

**重点页面**
- 接口排查：当前代码路径包含按环境 Base URL 发送请求的能力，因此 UI 必须按“可能真实发送”设计；按钮、环境、认证携带状态和确认弹窗须共同说明。Postman/cURL 草稿生成必须独立命名，禁止与实发混淆。
- SQL 控制台与日志排查：保留“AI 只生成草案、不自动执行”“仅白名单只读命令可执行”的近操作提示；“执行当前 SQL”“执行到当前终端”必须展示实际目标。
- 加解密：保持“本地处理、内容不保存”“密钥仅内存”的状态说明；清空按钮应明确清空范围。

## 4. P1：建议在全套 UI 设计中统一收敛的文案

### 4.1 动作命名一致性

| 当前形式 | 问题 | 推荐形式 |
|---|---|---|
| “新增” | 对象需依赖上下文猜测 | “新增服务器”“新增系统”“新增需求” |
| “编辑” | 多对象页面不够明确 | 行内可保留“编辑”；工具栏/菜单用“编辑服务器”“编辑需求” |
| “删除” | 未指出删除范围 | “删除选中需求”“删除当前配置”；确认框列出对象数量与名称 |
| “选择” | 未说明选择什么 | “选择目录”“选择文件”“选择日志文件” |
| “打开” | 可能是目录、详情、路径或页面 | “打开目录”“打开路径”“在格式工具中打开” |
| “预览” | 不说明预览对象 | “预览日志截取”“生成 SQL 预览” |
| “发送” | 可能是命令、请求或上下文 | “发送到当前终端”“发送给 AI”“向环境发送请求” |

### 4.2 专业模块高频文案治理

#### SQL 升级与 SQL 控制台

| 当前文案 | 统一后文案 | 说明 |
|---|---|---|
| 发版联动 | SQL 整理与导出 | 该页承担 SQL 输入、AI 辅助、预检、预览与本地导出；避免与需求管理的“上线联动”混淆 |
| 编写 / 优化 | AI 生成 SQL / AI 优化 SQL | 明确会调用内网模型，且只生成草稿、不自动执行 |
| 清空 | 清空 SQL 输入与预览 | 实际同时清除输入和三类预览，需说明范围 |
| 检查 SQL | SQL 预检（离线） | 明确为规则校验，不等同真实数据库编译/执行验证 |
| 生成预览 | 生成交付预览 | 明确生成升级、回滚、校验等交付物预览 |
| 导出全部 | 导出 SQL 交付包 | 明确写出多个本地交付文件；邻近展示系统、环境、输出目录 |
| 验证 SQL | 预检结果 / 校验结果 | 该 Tab 主要承载离线检查结果，不暗示已在目标库验证 |
| 复制链接 | 复制 SVN 地址 | 指出复制对象 |

#### 接口排查与请求验证

| 当前文案 | 统一后文案 | 说明 |
|---|---|---|
| 请求测试 | 请求验证 | 当前存在实际 HTTP 请求能力，不能与 Postman/cURL 草稿混同 |
| 发送 | 发送请求 | 按 P0-00 同时显示环境、Host、URL 与认证状态 |
| 测试 | 测试监听 | 说明测试对象，避免与请求验证混淆 |
| 清空 | 清空当前会话 | 声明仅清除本次捕获会话，确认框展示条数且不影响浏览器 |
| 保存接口 | 保存为本地接口模板 | 明确是本地保存，而非向服务端发送 |
| 已保存 / 发送记录 | 本地接口模板 / 本地发送记录 | 若记录仅在内存则用“本次发送记录”；不可用泛化“历史” |
| 清空历史 | 清空本地发送记录… | 确认前先展示条数、分类/搜索范围与持久范围 |
| 过滤 | URL 重写规则 | 该处是地址规则，不是会话筛选 |
| 导出明细 / 导入明细 | 导出当前会话明细 / 导入请求明细 | 明确内容对象与导入后的落点 |
| Headers / Params / Body | 请求头（Headers）/ 参数（Params）/ 正文（Body） | 中文产品中统一结构词语言，技术协议名可保留英文 |

#### SSH、日志排查与运维

| 当前文案 | 统一后文案 | 说明 |
|---|---|---|
| 会话 | SSH 会话排查 | 与接口/模型会话区分 |
| 设置 | 日志设置 | 与全局设置区分 |
| 打开 / 选用 | 打开远端目录 / 用作日志路径 | 明确远端对象与带入结果 |

终端 Tab 初始名统一为“会话 1 · 未连接”；连接后改为“{主机名} · 已连接”，同名时追加序号。关闭图标必须具有“关闭此 SSH 会话（将断开当前标签，不影响其他标签）”的 Tooltip 和可访问名称。

### 4.3 Tab 页签规范

已验证现有可见业务 Tab 均有文字，包括：
- SQL/发版：升级准备、发版联动、系统配置、升级 SQL、回滚 SQL、验证 SQL；
- 接口排查：请求/响应/详情/请求测试等；
- 加解密、格式工具、证件类型、需求管理等页签均有可读标题。

后续全套设计强制要求：
1. Tab 使用名词或明确工作对象，不用“其他”“更多”“内容”等模糊词。
2. 同一层 Tab 不混用对象名、动作名与状态名；例如“结果/消息/历史”可并列，“生成/结果/设置”则应评估是否为不同层级。
3. 可关闭 Tab 必须保留标题，关闭按钮需 Tooltip“关闭当前 SQL 标签”或同类具体表述。
4. 小窗口 Tab 溢出时采用可滚动或“更多”菜单，但激活页标题必须完整可见。

### 4.4 统一术语表与动词边界

| 概念 | 推荐主术语 | 禁止/避免混用 |
|---|---|---|
| 版本交付准备 | 升级准备 | 发版联动 / 发布与联动 / 升级资料随机互换 |
| 交付产物 | 升级材料 | 资料 / 材料混用 |
| 需求日期阶段 | 计划上线 / 实际上线 | 上线、发布、发版交替作为同一字段名称 |
| 需求详情工作域 | 文件与 SVN / 关联 SQL / 上线与联动 | 文件库 / SQL / 发版 / 发布与联动混用 |
| 接口保存项 | 本地接口模板 | 已保存 / 接口库（不说明本地性） |
| 接口记录 | 本地发送记录 / 本次发送记录 | 历史（不说明持久范围） |
| SSH 动作 | 执行命令 | 发送（单独使用） |
| HTTP 动作 | 发送请求 | 发送（单独使用） |
| 模型动作 | 发送消息 | 发送（单独使用） |
| 无副作用文本转移 | 填入 / 载入 / 送至 | 打开 / 发送（不区分副作用） |

**动词使用规则**：
- “新增”仅用于创建记录；“添加”用于为现有对象增加内容；“导入”表示文件进入系统；“载入/填入”表示只带入编辑区、不保存；“导出”表示写出本机文件；“提交”专指写入版本库。
- 任何“清空 / 删除 / 还原 / 保存 / 更新 / 执行 / 发送”都必须加对象；远端影响还必须展示目标环境、主机、路径或版本库。

### 4.5 图标与 Tooltip 规范

| 场景 | 当前发现 | 强制要求 |
|---|---|---|
| 日志排查刷新目录/日志文件 | 按钮无文字，但 Tooltip 已明确 | 可以保留；Tooltip 必须是完整动词短语，例如“刷新当前目录” |
| 接口排查“列设置” | 有文字但无 Tooltip | 可接受；建议补 Tooltip“选择会话表显示列”，改善键盘/新手发现性 |
| 业务原生图标操作 | 需与 Qt 原生箭头区别 | 业务按钮无文字时必须有 Tooltip；Qt 自带日历/Tab 滚动箭头不纳入该项 |
| “更多”收纳 | 多处有“更多”与完整菜单项 | 菜单项必须保留原动作完整文案；禁止把危险动作只藏在无说明图标中 |

### 4.6 下拉框与筛选条规范

1. **筛选下拉**：必须有“全部 X”复位项，如“全部状态”“全部类型”“全部分类”。
2. **枚举下拉**：首项必须是实际默认值，或为“请选择 X”；禁止首项留空。
3. **依赖下拉**：未满足依赖时为“请先选择 X”；无可选数据时为“暂无 X，请先新增/配置”。
4. **高风险环境下拉**：环境名称需要完整显示（如“集成环境 / 用户环境 / 生产环境”），执行前再次展示当前环境；不能仅用颜色或缩写区分。
5. **空下拉不可无解释地启用**：如可输入，应在 placeholder 或 Tooltip 写明可输入规则；如不可输入，应禁用并解释原因。
