# PengToolsHub V4.27 Private 发布说明

**构建时间以 `resources/build_info.json` 为准。**  
产物：`PengToolsHub_Offline_Setup.zip`、`dist\PengToolsHub.exe`。

## 本期包含

- 工作台、证件类型、升级准备/发版、接口文档更新、车辆 VIN、网关解密、运维助手、设置
- 日报、需求管理、格式工具、接口排查、日志排查
- 三套浅色主题 + 墨黑；旧 `night` 映射到墨黑
- 证件/VIN 可生成更完整的测试字段；悬浮栏可预览证件号、车牌、VIN、发动机号，双击复制单字段
- 需求可送到升级准备并勾选来源条目

## 限制（发给使用人时必须说明）

- 离线桌面工具，无账号、无云同步、无在线更新
- 证件、VIN、企业信息均为**模拟测试数据**，不得当作真实证照或上牌资料
- 接口排查仅允许本机 `127.0.0.1`，禁止把代理暴露到局域网
- 抓到的请求/响应/令牌只留在内存，不清空前不要当已落盘
- SVN 检出/提交需在**客户内网**验证，本开发环境无法代验
- 自我学习模块仍为彩蛋，不出现在普通说明里

## 安装与升级

1. 解压 zip，运行 `setup.cmd` 或直接打开 `PengToolsHub.exe`
2. 升级只替换 EXE，**不要删除 `data` 目录**
3. 建议在空目录全新安装验收一次，再覆盖到日常目录
