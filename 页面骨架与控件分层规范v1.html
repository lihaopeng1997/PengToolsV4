一、核心原则（5 条）

  1. MUST 一页一锚点：每个页面必须有 L1 页头（标题 + 副标题 + 主操作），用户任何时刻能回答"我在哪、能干什么"。
  2. MUST 主操作唯一且位置固定：每页至多 1 个 primary 主操作，永远在 L1 右侧槽位；禁止散落到内容区内部。
  3. MUST 操作与筛选分离：会改数据的控件（按钮）进 L2 工具栏；只缩小数据视野的控件（搜索/下拉）进 L3 筛选条；两层禁止混放。
  4. MUST 语义色只按语义用：primary=推进、danger=不可逆破坏、ghost=低频次要；颜色不允许用于装饰。
  5. MUST 样式走 Token：所有新样式用现有 QSS objectName 与主题 Token；新增 Token 必须四主题（calm/clear/warm/black）全覆盖，ThemeManager.render() 校验未解析占位符必须通过。

六、L4 内容区规范

6.1 表面角色（现有三件套，禁止自造）

objectName视觉用途

6.2 分区标题

MUST 内容区内多分区必须用 #zone-title（左侧 2px 色条 + 11px 字距标题）；分区标题文案为名词短语，不带冒号句尾。

6.3 空状态规范（四要素模板）

📂
尚未关联需求
点击右上「新建需求」开始台账，或从需求目录扫描现有条目
扫描需求目录
要素规则级别
① 图标24–28px 灰调图标（emoji 或现有 icon_role）MUST
② 标题一句话说明空的原因（"尚未关联需求"），不用"暂无数据"这种无信息量文案MUST
③ 引导告诉用户第一步做什么（≤2 行）MUST
④ 行动按钮可选 ≤1 个 secondary 按钮，直接触发引导动作；无动作则省略MAY

6.4 表格 / 树 / 终端

  • MUST 表格一律 apply_table()；树一律 apply_tree()；生成结果锁行高用 finish_result_rows()。
  • MUST 列表类控件最后一列避免大片空白（URL 类列用 Stretch，沿用接口排查已验证做法）。
  • MUST 终端区继续用 TERM_* 独立 Token（深色岛），禁止绑回 CODE_BG（AGENTS.md 硬规则）。

十一、落地批次建议

批次内容验收
批次 0（前置）用户安排提交当前 3 个未提交文件；然后实施 §9 基础设施：QSS 两段 + make_empty_state + test_page_skeleton 自检（初始允许 3 个已知缺页头页面红灯，标记 expectedFailure）自检测试可运行；四主题 render 校验通过；敏感扫描 + build_release.ps1
批次 1（P0 页面）升级准备、命令库补页头与分层；接口排查按既有计划推进自检测试全绿（去掉 expectedFailure）；定向测试（test_release_ui / test_interface_*）
批次 2（P1 页面）证件/VIN/接口文档/模型工作台主操作上移；需求管理 L2 分组与文件库按钮改造；日报页头+保存上移；日志排查按钮分层对应定向测试 + 手工回归截图对比
批次 3（P2 收尾）空状态全量补齐；状态栏文案精简；设置页微调全页离屏截图对比（复用 outputs/ui_review_shots.py）

MUST 每批次完成 = 定向测试 + scan_release_secrets.py + build_release.ps1 + 三产物核对 + 精确提交推送（AGENTS.md 交付节奏）。

十二、Non-goals（本规范明确不做）

  • 不改任何业务逻辑：导航映射、_show_panel 副作用、信号连接、数据读写一律不动
  • 不引入新第三方库、不做在线资源、不改主题色值（只复用现有 Token）
  • 不重排 splitter 子控件顺序（响应式反方向坑，AGENTS.md 明令禁止）
  • 不动终端 TERM_* 色彩体系
  • 不做动画/转场类装饰（离线工具台以稳为先）

十三、全局验收标准（可直接执行）

  • 14 个 Stack 页面均存在 #page-header，标题与侧栏导航文案一致（zh/en 双语）
  • 每页 primary 按钮数 ≤1，且位于 L1 右侧槽位
  • #page-filter-bar 内无会改数据的按钮（列设置 ghost 白名单除外）
  • L2 工具栏按钮 ≤8，语义分组可视可辨；破坏性操作均带 confirm_action（取消默认焦点）
  • 所有表格/树/结果表经过 apply_table / apply_tree / finish_result_rows
  • 列表空态呈现四要素（图标/标题/引导/可选按钮）；依赖缺失仍走 status-banner
  • 纯图标按钮 100% 有 tooltip；≥6 连图标场景前 4 个带文字
  • 新增 QSS 无未解析 Token（ThemeManager.render() 通过）、四主题视觉抽查一致
  • 每轮改造后离屏截图与改造前对比无布局回归（复用 ui_review_shots.py）
  • 测试、敏感扫描、离线构建、产物核对、精确提交推送全链路完成
